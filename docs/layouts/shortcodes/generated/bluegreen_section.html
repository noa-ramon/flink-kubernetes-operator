kubernetes.operator.bluegreen.abort.grace-period
 10 min Duration The max time to wait for a deployment to become ready before aborting it.
kubernetes.operator.bluegreen.cutover.drain-confirmation-window
 30 s Duration How long the new deployment's backlog must be read as continuously empty before the cutover proceeds when bluegreen.cutover.wait-for-source-drain is enabled. The window is measured from the first zero reading of the current incarnation of the job - never from wall time alone: a single reading is not evidence, since sources initialise pendingRecords lazily and a restart wipes the gauge. The window restarts whenever a non-zero backlog is read, no source reports the metric, the job or one of its source vertices restarts, or the set of reporting sources changes.
kubernetes.operator.bluegreen.cutover.drain-timeout
 30 min Duration The max time to wait for the new deployment to drain its source backlog when bluegreen.cutover.wait-for-source-drain is enabled, measured from the moment the new deployment became ready. If exceeded, the transition is aborted: the new deployment is suspended and the previous one remains active.
kubernetes.operator.bluegreen.cutover.wait-for-source-drain
 false Boolean If enabled, the previous deployment is kept running until the new deployment has drained its source backlog (no pending records), instead of being deleted as soon as the new deployment is ready. A deployment restored from a savepoint is ready while it still replays the records produced during its own startup; for event time pipelines with a bounded allowed lateness, deleting the previous deployment during that catch-up leaves those records without a producer. Requires sources exposing the pendingRecords metric (e.g. KafkaSource); a job where no source reports it never confirms as drained and the transition is aborted once bluegreen.cutover.drain-timeout expires.

 0 ms Duration Configurable delay before deleting a deployment after being marked done.
kubernetes.operator.bluegreen.reconciliation.reschedule-interval
 15 s Duration Configurable delay to use when the operator reschedules a reconciliation.
